Подробное описание

Синглтон для управления TCP-соединением с сервером

Обеспечивает единственное TCP-соединение на весь клиент. Все окна отправляют запросы через NetworkManager::getInstance()->sendRequest(...) и подписываются на сигнал responseReceived(QString).
