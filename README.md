**GradientProject** — это высокопроизводительное клиент-серверное приложение (DLP/вычислительный модуль) на стеке **C++ / Qt 6**, разработанное для защищенного выполнения криптографических алгоритмов и методов математической оптимизации. 

Архитектура системы построена на базе изолированного кроссплатформенного сервера, управляющего транзакциями в СУБД, и десктопного GUI-клиента, взаимодействующих по кастомному текстовому TCP-протоколу.

---

## 🛠 Ключевой функционал системы

### 1. Информационная безопасность и криптография
* **Защита учетных записей:** Хеширование учетных данных по стандарту **SHA-256** на стороне сервера, исключающее хранение паролей в открытом виде.
* **Криптографические модули:** Реализация алгоритмов симметричного шифрования (**Шифр Виженера**) для демонстрации методов защиты текстовых каналов связи.
* **Разделение прав доступа (RBAC):** Интегрированная система ролей (**Администратор / Пользователь**). Административный модуль предоставляет сквозной аудит системных логов, ошибок и истории вычислений.

### 2. Вычислительная математика и оптимизация
* **Интерполяция сплайнами:** Модуль аппроксимации дискретных массивов данных с построением непрерывных гладких кривых.
* **Градиентный спуск:** Реализация численного метода многомерной оптимизации для поиска локальных минимумов целевых функций с настраиваемым шагом обучения (`learning rate`).

### 3. Системная архитектура и паттерны
* **Concurrency (Многопоточность):** Сервер поддерживает пул параллельных сокетов (`QList<QTcpSocket*>`) для асинхронного обслуживания множества одновременных подключений без блокировки ядра.
* **Паттерн Singleton (Одиночка):** Менеджеры баз данных (`DatabaseManager`) и сетевых соединений (`NetworkManager`) спроектированы как потокобезопасные синглтоны с автоматическим управлением жизненным циклом через классы-деструкторы (`SingletonDestroyer`).

* **Среда разработки:** Qt Creator / CLion, компилятор MinGW 64-bit / GCC

## Сетевой протокол (Custom TCP Protocol)

Клиент и сервер обмениваются текстовыми пакетами со строгим разделением токенов через символ `;`, завершающимися символами переноса строки `\r\n`. 

**Пример сценария (Интерполяция сплайнов):**
1. Клиент отправляет: `SPLINE;1.0,2.0,3.0;2.0,4.0,8.0;1.5\r\n`
2. Сервер парсит пакет в методе `parseRequest`, валидирует данные, логирует действие в БД и производит расчет.
3. Сервер возвращает ответ: `SPLINE_RESULT;3.14\r\n`
